소개

통계학을 전공하고 데이터사이언스대학원에서 공부하며, 데이터를 근거로 원인을 찾는 훈련을 해왔습니다. 노인 노쇠 코호트 데이터를 분석한 대학원 연구에서는 신체·인지·심리처럼 성격이 다른 변수를 정리하면서, 결측값과 이상치를 먼저 꼼꼼히 들여다보지 않으면 분석 결과가 쉽게 틀어진다는 것을 체감했습니다. Boruta로 유의미한 변수를 선별하고 K-means로 군집을 나눠 변수 조합별 위험 양상을 비교하는 과정에서, 데이터 하나하나의 신뢰성부터 확인하는 습관을 길렀습니다.

국가승인통계 공모전에서는 온실가스·발전량·에너지 소비처럼 성격이 다른 여러 공공 데이터를 교차 분석해 정책 결론을 도출한 경험이 있습니다. 하나의 데이터만 보고 판단하지 않고, 여러 출처를 겹쳐봐야 진짜 원인인지 확인할 수 있다는 것을 이때 배웠습니다.

최근에는 Kaggle 경진대회 데이터로 같은 습관을 더 엄격하게 적용해봤습니다. 그럴듯해 보이는 개선도 검증 방식을 바꿔보면 효과가 사라지는 경우가 있다는 걸 확인했고, 성능이 정체되는 지점은 데이터의 결측 패턴까지 파고들어 원인을 찾아냈습니다. 숫자가 좋아졌다고 바로 채택하지 않고, 그 개선이 우연이 아닌지부터 확인하는 게 이제는 습관이 됐습니다.

개인 프로젝트

학생 건강 위험 예측 — 불균형 데이터·성능 한계 분석

클래스 불균형 처리 · 결측 패턴·분포 차이 진단 · Fold-safe 검증 · 공개 코드 감사

Kaggle 경진대회 데이터 690,088행을 활용한 불균형 3-class 분류 프로젝트입니다. LightGBM 5-fold 기준 모델을 구축한 뒤 XGBoost 7-fold OOF 검증으로 성능을 개선했습니다. Target Encoding은 각 outer training fold 내부의 inner 5-fold에서 생성해 누수를 방지했으며, 다중 시드 배깅과 FT-Transformer 기반 Cross-family 혼합도 추가로 검증했습니다. Cross-family 혼합은 평가 fold를 제외한 나머지 fold에서 가중치를 선택했으나, 개선폭이 +0.000041에 그치고 fold별 우위가 안정적이지 않아 최종 모델에서는 제외했습니다. 원본 5만 행 데이터에서 학습한 생성 규칙을 대회 데이터로 전이하고, 수면시간 또는 스트레스 변수가 결측된 21.71%의 행이 Balanced Accuracy 잔여 간극의 54.97%를 설명한다는 점을 확인했습니다.

  • 검증 설계7-fold OOF 검증, outer fold 내부 5-fold Target Encoding, leave-one-outer-fold-out 앙상블 가중치 평가
  • 원인 분해결측치 21.71%인 행이 Balanced Accuracy 잔여 간극의 54.97%를 설명함을 정량 확인

2024 대한산업공학회 춘계공동학술대회에서 발표한 개인 연구입니다. 지도교수 지도 하에 데이터 전처리부터 분석·시각화까지 단독으로 수행했습니다. 노인 노쇠 코호트 데이터의 신체·인지·심리 변수군을 정리하며 결측값과 이상치를 먼저 확인하고, Boruta로 노쇠 예측에 유의미한 변수를 선택한 뒤 K-means로 변수군별 군집을 구성해 군집 조합별 위험 양상을 비교했습니다.
