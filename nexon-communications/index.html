소개

김태훈

통계학·데이터사이언스 전공 · 고객 응대와 게임 데이터 분석 경험

호주 워킹홀리데이 중 약 1년간 휴대전화 리테일 매장에서 고객을 직접 응대했습니다. 질문의 순서와 상품 설명 방식을 바꿔가며 고객의 반응을 살폈고, 다시 저를 찾는 단골 고객을 만들면서 좋은 서비스는 정해진 답을 반복하는 것이 아니라 상대에게 필요한 답을 찾는 일임을 배웠습니다. 이후 통계학과 데이터사이언스를 공부하며 개별 반응에서 반복되는 원인과 흐름을 찾는 방법을 익혔습니다.

던전앤파이터의 공식 문서와 경매장 데이터를 직접 수집·분석하며, 정보가 존재하는 것과 이용자가 필요한 답을 쉽게 찾는 것은 다른 문제라는 점을 확인했습니다. 입사하면 문의와 이용자 행동을 함께 살펴 반복되는 문제를 찾고, 데이터와 AI는 판단을 대신하는 수단이 아니라 더 빠르게 원인을 확인하기 위한 보조 도구로 활용하겠습니다.

업무 방식

문의 한 건을 처리하는 데서 끝내지 않고, 같은 문제가 반복되지 않도록 원인을 찾고 다시 확인합니다.

01

이용자 목소리 수집

문의 내용과 이용 상황을 함께 살펴 이용자가 실제로 막힌 지점을 확인합니다.

02

반복 문제 분류

비슷한 문의와 행동을 같은 기준으로 정리해 반복되는 유형과 우선순위를 찾습니다.

03

데이터로 원인 확인

게임 데이터와 사람의 직접 확인을 함께 사용해 추측과 실제 현상을 구분합니다.

04

개선 후 재측정

작은 범위에서 안내와 절차를 바꾸고 문의량, 완료율, 유지율의 변화를 확인합니다.

AI와 자동화는 반복 작업을 줄이는 데 활용하되, 적용 여부와 최종 판단은 사람이 확인합니다.
