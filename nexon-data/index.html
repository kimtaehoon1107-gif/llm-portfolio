문제

체결 API는 최근 100건 또는 최대 한 달 중 먼저 도달하는 한도까지만 제공합니다. 더 긴 시세 이력과 이벤트 전후 자료를 확보하려면 데이터를 직접 쌓아야 했습니다.

역할

API 수집·SQL 저장·시간봉 집계·웹 차트를 구현했습니다. 원본 체결과 시간봉을 대조하고, 집계 불일치나 지연이 발견되면 새 배포를 중단하도록 검증 절차를 구축했습니다.

판단 근거

빈 시간봉을 채우거나 공백 양쪽을 이어 붙이지 않고, 종목별 가장 긴 연속 완료 구간을 검정했습니다. 일반 아이템의 대표 가격은 최근 60분 VWAP, 카드는 단계별 최저 호가로 구분했습니다. 매물 감소에는 취소가 섞여 체결량과 합산하지 않았습니다.

결과

검정 가능한 15종 중 1종에서 Holm 다중 검정 보정 후 단기 반전 신호를 관측했습니다. 평가일 기준 1일 뒤 예측은 4종·15건에서 MAPE 2.32%로, 마지막 완료 일봉의 VWAP을 유지하는 기준선(1.97%)보다 오차가 컸습니다. 요일 효과는 표본 부족으로 판단을 보류했습니다.

예측은 평가일 이전 자료로 다시 학습하는 롤링 방식으로 점검했습니다. 백필을 포함한 체결 시각 기준의 과거 재구성이며, 당시 수집기가 보유했던 자료까지 재현한 평가는 아닙니다. 15건은 독립 표본 수를 뜻하지 않으며, 7일 뒤 예측은 아직 평가 가능한 사례가 없습니다.

문제

던전앤파이터 공식 정보가 여러 문서에 흩어져 있어 필요한 내용을 찾기 어렵고, 검색 결과가 있어도 답변 전체를 뒷받침하는지 따로 확인해야 했습니다.

공식 문서 수집과 정제, 키워드·벡터 결합 검색, 근거 원문 복원, 답변 생성 기준과 웹 데모까지 하나의 흐름으로 구현했습니다.

결과

A6 봉인 평가에서 사람 검수 기준으로 32문항 중 20문항이 통과했습니다. 목표 80%에 미달해 A6를 제품의 기본 답변 경로로 채택하지 않고, 실패 유형과 재현 자료를 공개했습니다.

분석 방식

무엇을 판단하기 위한 분석인지 먼저 정하고, 데이터 구조와 검증 기준을 만들어 결론과 한계를 함께 전달합니다. DNF 경매장 프로젝트에서는 다음 순서로 적용했습니다.

01

분석 질문 정하기

가격 변화에 단기 반전·지속 신호가 있는지, 예측 모델이 마지막 가격을 유지하는 기준선보다 나은지 별도 질문으로 나눴습니다.

02

데이터 구조화

체결과 호가를 구분하고 완료 시간봉·일봉을 분석 단위로 정했습니다. 원본과 집계를 대조하고, 빈 시간봉을 임의로 채우지 않았습니다.

03

분석하고 오류 확인하기

연속 시간봉의 분산비 검정에 Holm 보정을 적용했습니다. 예측은 평가일 이전 자료로 다시 학습하고, 마지막 완료 일봉 VWAP과 오차를 비교했습니다.

04

결과 공유와 다음 검증

기준선보다 큰 예측 오차와 표본 부족을 공개했습니다. 요일 효과의 해석은 보류하고, 관측이 쌓이면 검정 범위와 예측 평가를 확장하도록 정리했습니다.

데이터 분석으로 판단의 근거를 만들고, 이를 명확하게 전달해 더 효율적인 의사결정을 돕겠습니다.
