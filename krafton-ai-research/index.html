HOW I RESEARCH

연구 질문을 판단 가능한 실험으로 바꾸는 과정

프로젝트가 달라도 같은 순서로 확인합니다.

  1. 01질문 정의

    무엇을 개선하려는지 한 문장으로 좁힙니다.

  2. 02데이터 점검

    결측·중복·극단값과 데이터 생성 과정을 확인합니다.

  3. 03기준선 설정

    복잡한 방법이 단순한 방법보다 실제로 나은지 비교합니다.

  4. 04분리 평가

    개발에 쓰지 않은 데이터와 사람 검수로 다시 확인합니다.

  5. 05판단 기록

    적용 여부, 한계와 다음 실험을 함께 남깁니다.

제한된 거래 기록으로 가격 변화와 반복 패턴을 안정적으로 관찰할 수 있는가?

03 · 예측 모델과 데이터 품질2026.07 · 개인 프로젝트

학생 건강 위험 예측

약 69만 건의 불균형 데이터를 이용해 건강 위험 등급을 예측하고, 전체 성능 뒤에 가려진 집단별 차이를 분석했습니다.

연구 질문

모델 성능의 남은 한계는 알고리즘보다 데이터 특성에서 설명되는가?

검증 설계

교차검증과 학습 구간 내부 변수 생성으로 누수를 막고, 결측 집단 성능을 따로 측정했습니다.

관찰 결과

특정 결측 집단이 잔여 성능 격차의 54.97%를 설명했고 추가 모델의 개선은 0.000041에 그쳤습니다.

연구 판단

미미한 개선을 위한 복잡도 증가는 제외하고, 데이터 품질과 집단별 차이를 우선 과제로 남겼습니다.
