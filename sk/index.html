던전앤파이터 경매장 API는 최근 거래만 보여주기 때문에, 아이템별 거래와 매물을 주기적으로 모아 PostgreSQL에 가격 기록을 쌓는 개인 서비스를 만들었습니다. 수집이 늦어지거나 같은 거래가 두 번 들어오는 경우를 자동으로 점검하고, 시간 단위 집계가 맞는지 확인한 뒤 웹사이트로 배포합니다. 가격과 매물 수를 같은 시간축에서 비교하며, 통계 검정과 예측 결과에는 표본이 적거나 수집이 빠진 구간 같은 한계도 함께 적었습니다.

  • 예측 검증날짜별로 예측을 다시 평가해 직전 가격을 그대로 쓰는 방법과 비교하고, 예측의 한계도 공개

DNF Domain QA SLM/RAG v2

답할 수 있는 범위 판단 · 실패 원인 분석 · 같은 조건 비교 · 최종 검증 기준

던파 공식 문서를 근거로 답하되, 문서로 확인되지 않는 부분은 답하지 않는 질의응답 시스템을 목표로 했습니다. 1차 버전에서 나온 오류를 검색 실패, 근거 선택 실패, 답변·거절 실패로 나눠 살펴봤고, 같은 검색 결과를 규칙 기반 RAG, 학습 전 모델, 학습한 모델에 똑같이 넣어 학습 효과만 따로 비교했습니다.

  • 평가 설계답할 수 있는 질문, 일부만 답할 수 있는 질문, 답하면 안 되는 질문, 안전 관련 질문으로 나눠 근거 사용과 거절을 따로 측정
  • 학습 실험정답 근거와 헷갈리는 문서를 함께 넣은 학습 데이터(RAFT)로 Qwen 모델을 LoRA 방식으로 학습
  • 같은 조건 비교검색 결과를 고정한 뒤 규칙 기반 RAG, 학습 전 모델, 학습한 모델의 차이를 비교
  • 최종 판단학습한 모델은 출처 표시와 부분 답변이 좋아졌지만, 거절 기준에 미치지 못해 최종 검증으로 넘기지 않음

학생 건강 위험 예측 — 불균형 데이터·성능 한계 분석

불균형 데이터 분류 · 결측 패턴 분석 · 데이터 누수 방지 검증 · 공개 코드 점검

Kaggle 경진대회 데이터 690,088행으로 건강 위험 등급을 세 단계로 분류한 프로젝트입니다. 등급마다 데이터 수 차이가 커서, 이 불균형을 다루는 것이 핵심이었습니다. LightGBM 5-fold 모델을 기준으로 잡고, XGBoost 7-fold 교차검증(OOF)으로 성능을 높였습니다. Target Encoding은 각 학습 fold 안에서 다시 5-fold로 나눠 만들어, 평가 데이터 정보가 학습에 섞이지 않게 했습니다. 여러 시드로 학습한 모델을 합치거나 FT-Transformer와 섞는 방법도 시험했지만, 개선 폭이 +0.000041에 그치고 fold마다 결과가 들쭉날쭉해 최종 모델에서는 뺐습니다. 원본 5만 행 데이터에서 찾은 생성 규칙을 대회 데이터에 적용해 보고, 수면 시간이나 스트레스 값이 비어 있는 21.71%의 행이 남은 Balanced Accuracy 격차의 54.97%를 설명한다는 점도 확인했습니다.

  • 검증 설계7-fold 교차검증, 학습 fold 안에서만 만든 Target Encoding, fold를 하나씩 빼 가며 앙상블 가중치 평가
  • 원인 분석값이 비어 있는 21.71%의 행이 남은 성능 격차의 54.97%를 설명한다는 것을 수치로 확인

  • 추천 구조 변경여러 조건을 한꺼번에 반영하는 추천 방식의 한계를 확인하고, 항목(Aspect) 중심 구조로 변경
